Dataset preparation for ResNet

The dataset selected above is reused here. Fashion-MNIST, PneumoniaMNIST and synthetic bars support classification. BUS-UCLM and annotated imports support mask tasks. Grayscale inputs are replicated into RGB and letterboxed. BUS-UCLM class labels are derived from expert mask colours.

Official dataset

BUS-UCLM uses this saved folder before attempting a download. CSV imports have a separate file path.

CSV columns: id, patient, image, mask, label, mask_encoding. Labels: 0 normal, 1 benign, 2 malignant. Mask encoding: binary or rgb-lesion. Images and masks must have matching dimensions.

Residual architecture and task configuration

Small/custom models use raw [0,1] input coordinates, without BatchNorm. The ResNet-50 preset uses its standard ReLU/BatchNorm architecture and global average pooling; custom stage controls apply only to the small/custom builders. BatchNorm running statistics stay fixed during training. The analysis uses evaluation mode and includes the recorded ImageNet input normalization as an affine graph operation. Decoder upsampling is nearest-neighbour.

Historical checkpoints include optimizer state and can each occupy several hundred MiB. Resolution strongly affects activation memory; CPU training at larger resolutions is slow. A synthetic dataset checks software operation, not medical performance.
