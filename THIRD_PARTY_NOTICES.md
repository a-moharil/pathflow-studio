# Third-party components

`lab/static/vendor/plotly.min.js` is Plotly.js v2.35.2, bundled from the Plotly Python 5.24.1 distribution. Copyright Plotly, Inc. MIT licensed; see the license file alongside it and the preserved header. No Python Plotly installation is needed to run this app.

Python dependencies retain their respective licenses. Dataset downloads retain their dataset-specific terms and citations. Fashion-MNIST is loaded via torchvision; PneumoniaMNIST via MedMNIST. Those datasets are not redistributed in this archive.

## Bundled fonts (0.16.1)

`lab/static/vendor/fonts` contains Latin variable subsets, as packaged by Fontsource 5.3.0, of:

- Archivo (width and weight axes), Copyright 2020 The Archivo Project Authors (Omnibus-Type) — SIL Open Font License 1.1 (`OFL-Archivo.txt`)
- Martian Mono (width and weight axes), Copyright 2020 The Martian Mono Project Authors (Evil Martians) — SIL Open Font License 1.1 (`OFL-MartianMono.txt`)
