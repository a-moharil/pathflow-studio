What does Integrated Gradients explain?

Move from reference x° to input x along x(α) = x° + α(x − x°). IG accumulates each coordinate’s gradient along that path and multiplies by its endpoint change. Signed IG sums approximately to g(x) − g(x°); its residual measures quadrature completeness, not every pixel’s error. This path is through input space, not a complete path through the execution graph. Intermediate images need not be realistic. IG is not a pixel-deletion effect.
