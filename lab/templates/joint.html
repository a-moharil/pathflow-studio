Joint healthcare laboratory

ResNet-50 classification and lesion segmentation, with checkpoint-bound computational fields.

Data preparation

BUS-UCLM provides native 1024 × 768 ultrasound images, lesion masks and patient identifiers. Training uses a recorded letterbox resolution. Classification labels in this adapter come from the expert mask colours; they are not independent annotations.

Official dataset

BUS-UCLM uses this saved folder before attempting a download. CSV imports have a separate file path.

CSV columns: id, patient, image, mask, label, mask_encoding. Labels: 0 normal, 1 benign, 2 malignant. Mask encoding: binary or rgb-lesion. Images and masks must have matching dimensions.

Design experiment

BatchNorm running statistics stay fixed during training. The analysis uses evaluation mode and includes the recorded ImageNet input normalization as an affine graph operation. Decoder upsampling is nearest-neighbour.

Historical checkpoints include optimizer state and can each occupy several hundred MiB. Resolution strongly affects activation memory; CPU training at larger resolutions is slow. A synthetic dataset checks software operation, not medical performance.
