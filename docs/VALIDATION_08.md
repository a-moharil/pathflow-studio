# Evidence 08 validation

The release is built on 0.6.1, with cumulative installation also supported from delivered 0.6.0 source.

Validation includes the complete Python regression suite; independent checks of occurrence interventions against parameter-edited networks, occurrence gradients against autograd, Field B subset/mass identities, ReLU compensation invariance, undefined measures and frozen checkpoint integrity. Browser checks cover new evidence modes, prior healthcare workflows and prior fitting/geometry workflows. Existing Node checks cover anchors/cameras, independent 2-D geometry, all edges, all-node labels, fidelity fallbacks and Observatory context.

Evidence browser checks exercise measured-frame playback, presentation mode, PNG/JSON/CSV/WebM downloads, saved-result reopening and stale-request rejection. Installer checks apply both baseline patches in disposable Git repositories and verify the complete target source and retained workspace files.

These are synthetic CPU and software-integrity checks, not a clinical validation or a demonstrated advantage over attribution methods on medical cohorts. IG remains a numerical quadrature with reported completeness residual. Representation fidelity is distinct from intrinsic-metric computation.
