Measure and metric definitions

Complete conditional paths use the actual input contrast and finite operation responses. Structural paths use unit input masses, unit activation coefficients and fixed affine coefficients. The optional He convention divides learned weights by √(2/fan-in); unequal residual route depths make this a different structural measure. Neither choice changes the conditional response.

For full scalar geometry, K comprises every scalar occurrence feeding one operation instance, including all branches of an additive merge. Enrichment is |K|Fₑ/Σₐ∈K Fₐ and length is (enrichment + ε)−p. Zero-mass classes have undefined enrichment and use the explicitly declared metric-only zero extension. ε does not normalize a vanished path measure. Max-pool structural coefficients use a declared uniform amplitude over valid candidates. Low-dimensional embeddings remain fitted representations, with distortion diagnostics.

Transforms resample the original contrast endpoints at the frozen checkpoint. Labels are not assumed invariant. The mask readout region remains fixed in output coordinates.

Interpret the maps
Field A allocates normalized squared complete-path mass to input origins. It discards overall amplitude and signs. IG integrates input derivatives along the straight input interpolation and reports a signed net attribution; its sum approximates the output contrast, with numerical residual shown above. Increase integration intervals if this residual is large. Grad-CAM combines feature activations with endpoint gradients and is displayed at the selected layer's native resolution. These are complementary questions, not interchangeable measures of causality.
Field B, when available, is the baseline Conv1 occurrence mass belonging to the selected stem-channel support. Deeper selections have native feature-coordinate occupation, not an invented raw-image footprint. Intervention effects are measured separately for both heads. Normalized occupation does not measure absolute output response. In a deep signed graph, subtracting very large P and N can lose precision. The output audit uses independently propagated signed contrasts; cancellation values near one require this numerical caution.

Structural and conditional geometry
The operation quotient displays the whole architecture with exact aggregated occurrence marginals. Its distances are quotient distances, not full scalar execution distances.
