Interpret the maps

Field A allocates normalized squared complete-path mass to input origins. It discards overall amplitude and signs. IG integrates input derivatives along the straight input interpolation and reports a signed net attribution; its sum approximates the output contrast, with numerical residual shown above. Increase integration intervals if this residual is large. Grad-CAM combines feature activations with endpoint gradients and is displayed at the selected layer's native resolution. These are complementary questions, not interchangeable measures of causality.

Field B, when available, is the baseline Conv1 occurrence mass belonging to the selected stem-channel support. Deeper selections have native feature-coordinate occupation, not an invented raw-image footprint. Intervention effects are measured separately for both heads. Normalized occupation does not measure absolute output response. In a deep signed graph, subtracting very large P and N can lose precision. The output audit uses independently propagated signed contrasts; cancellation values near one require this numerical caution.

This is the induced Conv1 occurrence subgraph around its central 3 × 3 destination window, with complete-model edge marginals. Distances are measured inside this selected subgraph. This is not a full-network embedding or BCANw measurement. The experimental metric uses topology-reference marginal r and length 1 / (F/r + 0.03).
